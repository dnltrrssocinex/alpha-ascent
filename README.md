# Alpha Ascent — website

Static homepage for Alpha Ascent. Black-and-white draft built on the Motions interaction library.

- `site/` — the website (`index.html`, `styles.css`, `main.js`)
- `.github/workflows/pages.yml` — deploys `site/` to GitHub Pages on every push to `main`

## Run locally

Any static server works, for example:

```bash
npx -y serve site -l 4173
```

## Status

Draft. The signup form is a preview and sends nothing. Membership details, legal pages and business
information are placeholders until confirmed.
